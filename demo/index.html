FAQ Chat Widget

A zero-dependency chat bubble that answers from a local FAQ file. The sample FAQ below is for a fictional web agency (prices and policies are made up). Try English or Bangla: price, দাম কত, delivry time (typo), বিকাশ, ৩০ দিন.

Install with one tag:

<script src="faq-chat-widget.min.js" defer
  data-faq-url="faq.json"
  data-lang="auto"
  data-theme="auto"
  data-primary="#0b7a5b"
  data-whatsapp="8801XXXXXXXXX"></script>
